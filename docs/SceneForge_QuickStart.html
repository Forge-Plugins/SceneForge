Welcome to the SceneForge beta

SceneForge Outliner 1.0 beta · 3ds Max 2027 · Quick start

Thank you for testing SceneForge Outliner. This beta has no limits and needs no key. Install it first (see the Installation sheet), then follow these steps.

Quick start

Five minutes, seven steps. You need 3ds Max 2027 with SceneForge installed and any scene open (the bigger, the better).

1. Open the panel

  • Right after installing, answer Yes to Open the panel now to check that it works?
  • Later: main menu SceneForge > SceneForge Outliner. The SceneForge menu appears after you restart 3ds Max once.
  • Or: Customize > Customize User Interface, category SceneForge, command SceneForge Outliner. Give it a keyboard key or put it on a toolbar.
  • The panel opens as a docked window. The first opening loads the plugin and takes a moment; after that it just shows the panel.

2. Find an object with the filter

  • Click the filter field at the top (its grey hint starts with filter: name, type:Box ...).
  • Type part of a name, for example chair. The list shrinks while you type. Case does not matter.
  • Try a key: type:Box, layer:Walls*, -hidden:1 (the minus means NOT). A space between terms means AND.
  • Or click a chip under the field: Geometry, Lights, Cameras ... Hidden, Frozen, Selected, Last 10 min. The x button clears the chips.
  • Delete the text to see the whole scene again. The ? button shows the full filter cheat sheet.

3. Select

  • Click a row: the object is selected in the scene. Ctrl+click adds or removes, Shift+click selects a range.
  • Ctrl+drag over rows selects every row you pass. (A drag without Ctrl moves objects: onto another row it links them as children.)
  • Ctrl+A selects everything the list shows (the filter result, not the whole scene). Ctrl+D clears, Ctrl+I inverts.
  • Select something in the viewport: the list highlights it and scrolls to it.

4. Hide and freeze

  • The State column has an eye (visibility) and a snowflake (freeze). Click them.
  • On a selected row the click acts on all selected objects; on any other row it acts on that row only.
  • Or right-click a row: Hide, Show, Freeze, Unfreeze.
  • Ctrl+Z undoes it in one step (also while the panel has focus).

5. The command palette: Ctrl+P

  • Click inside the panel first. Outside the panel Ctrl+P is the 3ds Max Pan tool.
  • Type what you want to do. Letters need not be next to each other: brn finds Batch rename.
  • Arrows choose, Enter runs, Esc closes. Grey commands need something first (usually a selection).
  • The Menu button (first on the top bar) has the same commands in groups, without typing.

6. Lenses: group the list

  • On the top bar open the drop-down that shows no grouping.
  • Choose by layer (Layer Explorer), by class, by material, by instance, by group or by face count.
  • A lens changes only the view, never the scene. The filter and the selection keep working.
  • Under the layer lens, right-click a layer header for layer commands (hide, freeze, rename, ...).

7. Isolate

  • Select the objects you want to work on, click into the panel and press Ctrl+Alt+Q.
  • Everything else is hidden. A bar above the list shows Exit isolation (Ctrl+Alt+Q).
  • Press Ctrl+Alt+Q again (or click the bar) to bring back exactly what was visible before.
  • Isolation is a mode, not an edit: Ctrl+Z does not leave it. The 3ds Max Alt+Q isolation is a separate tool.
Tip. Every button and command has a tooltip. Hover for a second and the panel tells you what it does and what it will not do.

How to send feedback

  • SceneForge > Report a bug... copies your set-up details to the clipboard and shows links to the GitHub form and the e-mail address. Describe the steps, then paste (Ctrl+V).
  • The details include your install folder (with your Windows user name) and the last lines of the panel log (file and object names). Read them before posting publicly; for client scenes use e-mail.
  • Ideas: SceneForge > Suggest a feature...
  • github.com/Forge-Plugins/SceneForge/issues · forgeplugins@gmail.com
  • What is planned: the SceneForge roadmap on Trello (SceneForge > Roadmap (Trello)).
  • Full guide: SceneForge > Documentation (works offline), or online.
