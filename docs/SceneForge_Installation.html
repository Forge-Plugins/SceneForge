Installing SceneForge Outliner

SceneForge Outliner 1.0 beta · 3ds Max 2027 · install, update, uninstall

Requirements

  • 3ds Max 2027 on Windows. This package supports no other version: the installer checks the version and stops if it does not match.
  • No internet connection. SceneForge works offline and sends nothing anywhere.
  • About 3 MB of disk space in your 3ds Max user folder. No administrator rights are needed.
Beta. This beta build has no limits and needs no license key. SceneForge > License... shows the license as active for Beta.

Install

  1. Save your work. Start 3ds Max 2027 (an empty or an open scene, both are fine).
  2. Drag the SceneForge .mzp file you received from Windows Explorer onto a 3ds Max viewport. (Alternative: Scripting > Run Script... and pick the .mzp file.)
  3. The installer checks the 3ds Max version, copies the files and checks every copied file.
  4. It asks: SceneForge Outliner has been installed. Open the panel now to check that it works?
    Yes opens the panel right away (the installation summary then goes only to the MAXScript Listener, F11).
    No shows the summary window: the copied files, the path of this user guide, how to start the panel, where to report bugs and the line that uninstalls SceneForge.
  5. Restart 3ds Max to get the SceneForge menu in the main menu bar. The commands in Customize User Interface work at once, without a restart.

After a restart the main menu bar has a SceneForge menu with ten commands. The same commands are in Customize > Customize User Interface, category SceneForge, so you can give them keys, toolbar buttons or quad menu entries.

Where the files go

Everything goes into your own 3ds Max user folder, normally %LOCALAPPDATA%\Autodesk\3dsMax\2027 - 64bit\ENU\ (ENU is the language of 3ds Max). The summary window shows the exact paths.

FolderContents
scripts\SceneForge\The plugin: panel, core, scene listener, start script, uninstaller, this user guide and SceneForge_installed.txt (the list of installed files).
usermacros\SceneForge.mcrThe ten commands of the SceneForge category.
scripts\startup\A small script that adds the SceneForge menu when 3ds Max starts.
plugcfg\SceneForge\Your settings, created on first use: preferencje.json (preferences), skroty.json (your shortcuts), makra.json (macros), saved views, scene rules, panel state and the panel log dziennik_panelu.txt.
Language profiles. 3ds Max keeps a separate user folder per language. If you install while running 3ds Max in English and later start it in another language, install SceneForge again in that language.

Update to a newer build

  • Drag the new .mzp onto a viewport, exactly like the first time.
  • The installer replaces the plugin files and removes the older versions. Your settings, shortcuts, macros, saved views and rules in plugcfg\SceneForge are kept.
  • If the panel was open, answer Yes to open the new panel, or simply restart 3ds Max. If you answer No, the previous panel keeps running until the next restart.

Uninstall

  1. Scripting > Run Script..., open the folder scripts\SceneForge (the installation summary shows its full path) and run the file SceneForge_odinstaluj_v...ms.
  2. Or: Scripting > New Script, paste the lines below and press Ctrl+E (Tools > Evaluate All):
(
  SF_odinst = getFiles ((getDir #userScripts) + "\\SceneForge\\SceneForge_odinstaluj_v*.ms")
  sort SF_odinst
  if SF_odinst.count > 0 then fileIn SF_odinst[SF_odinst.count]
  else messageBox "SceneForge is not installed."
)
  • It removes: the open panel (it first leaves isolation and the viewport filter mode and restores painted wireframe colours), the scene callbacks and the scene listener, the SceneForge columns in the native Scene Explorer, the loaded core, the files listed in SceneForge_installed.txt, the commands file, the startup menu script and the listener's own log file.
  • It keeps: your settings in plugcfg\SceneForge and any file in the plugin folder that SceneForge did not put there (the folder then stays). The final window lists what was removed, what was kept and where; delete the kept files by hand if you do not need them.
  • Data already saved inside your .max files stays in those files (see Privacy & footprint in the User Guide).
  • The menu entry disappears after you restart 3ds Max.

Troubleshooting

ProblemWhat to do
