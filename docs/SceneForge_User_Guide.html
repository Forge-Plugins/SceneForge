SceneForge Outliner

User Guide · 1.0 beta for 3ds Max 2027 · by ForgePlugins

SceneForge Outliner is a fast scene browser for 3ds Max: one docked panel with a powerful filter, lenses, layers, isolation, reports and batch tools. This guide covers the beta build. Every command described here is in the panel; hover over any button for its tooltip.

Beta. This build has no limits and needs no license key. The License... window shows the license as active for Beta. Please report anything odd: see Reporting bugs.

1. Quick start

Five minutes, seven steps. You need 3ds Max 2027 with SceneForge installed and any scene open (the bigger, the better).

1. Open the panel

  • Right after installing, answer Yes to Open the panel now to check that it works?
  • Later: main menu SceneForge > SceneForge Outliner. The SceneForge menu appears after you restart 3ds Max once.
  • Or: Customize > Customize User Interface, category SceneForge, command SceneForge Outliner. Give it a keyboard key or put it on a toolbar.
  • The panel opens as a docked window. The first opening loads the plugin and takes a moment; after that it just shows the panel.

2. Find an object with the filter

  • Click the filter field at the top (its grey hint starts with filter: name, type:Box ...).
  • Type part of a name, for example chair. The list shrinks while you type. Case does not matter.
  • Try a key: type:Box, layer:Walls*, -hidden:1 (the minus means NOT). A space between terms means AND.
  • Or click a chip under the field: Geometry, Lights, Cameras ... Hidden, Frozen, Selected, Last 10 min. The x button clears the chips.
  • Delete the text to see the whole scene again. The ? button shows the full filter cheat sheet.

3. Select

  • Click a row: the object is selected in the scene. Ctrl+click adds or removes, Shift+click selects a range.
  • Ctrl+drag over rows selects every row you pass. (A drag without Ctrl moves objects: onto another row it links them as children.)
  • Ctrl+A selects everything the list shows (the filter result, not the whole scene). Ctrl+D clears, Ctrl+I inverts.
  • Select something in the viewport: the list highlights it and scrolls to it.

4. Hide and freeze

  • The State column has an eye (visibility) and a snowflake (freeze). Click them.
  • On a selected row the click acts on all selected objects; on any other row it acts on that row only.
  • Or right-click a row: Hide, Show, Freeze, Unfreeze.
  • Ctrl+Z undoes it in one step (also while the panel has focus).

5. The command palette: Ctrl+P

  • Click inside the panel first. Outside the panel Ctrl+P is the 3ds Max Pan tool.
  • Type what you want to do. Letters need not be next to each other: brn finds Batch rename.
  • Arrows choose, Enter runs, Esc closes. Grey commands need something first (usually a selection).
  • The Menu button (first on the top bar) has the same commands in groups, without typing.

6. Lenses: group the list

  • On the top bar open the drop-down that shows no grouping.
  • Choose by layer (Layer Explorer), by class, by material, by instance, by group or by face count.
  • A lens changes only the view, never the scene. The filter and the selection keep working.
  • Under the layer lens, right-click a layer header for layer commands (hide, freeze, rename, ...).

7. Isolate

  • Select the objects you want to work on, click into the panel and press Ctrl+Alt+Q.
  • Everything else is hidden. A bar above the list shows Exit isolation (Ctrl+Alt+Q).
  • Press Ctrl+Alt+Q again (or click the bar) to bring back exactly what was visible before.
  • Isolation is a mode, not an edit: Ctrl+Z does not leave it. The 3ds Max Alt+Q isolation is a separate tool.
Tip. Every button and command has a tooltip. Hover for a second and the panel tells you what it does and what it will not do.

2. Installation

Requirements

  • 3ds Max 2027 on Windows. This package supports no other version: the installer checks the version and stops if it does not match.
  • No internet connection. SceneForge works offline and sends nothing anywhere.
  • About 3 MB of disk space in your 3ds Max user folder. No administrator rights are needed.
Beta. This beta build has no limits and needs no license key. SceneForge > License... shows the license as active for Beta.

Install

  1. Save your work. Start 3ds Max 2027 (an empty or an open scene, both are fine).
  2. Drag the SceneForge .mzp file you received from Windows Explorer onto a 3ds Max viewport. (Alternative: Scripting > Run Script... and pick the .mzp file.)
  3. The installer checks the 3ds Max version, copies the files and checks every copied file.
  4. It asks: SceneForge Outliner has been installed. Open the panel now to check that it works?
    Yes opens the panel right away (the installation summary then goes only to the MAXScript Listener, F11).
    No shows the summary window: the copied files, the path of this user guide, how to start the panel, where to report bugs and the line that uninstalls SceneForge.
  5. Restart 3ds Max to get the SceneForge menu in the main menu bar. The commands in Customize User Interface work at once, without a restart.

Messages you may see instead:

Where the files go

Everything goes into your own 3ds Max user folder, normally %LOCALAPPDATA%\Autodesk\3dsMax\2027 - 64bit\ENU\ (ENU is the language of 3ds Max). The summary window shows the exact paths.

Update to a newer build

  • Drag the new .mzp onto a viewport, exactly like the first time.
  • The installer replaces the plugin files and removes the older versions. Your settings, shortcuts, macros, saved views and rules in plugcfg\SceneForge are kept.
  • If the panel was open, answer Yes to open the new panel, or simply restart 3ds Max. If you answer No, the previous panel keeps running until the next restart.

Uninstall

  1. Scripting > Run Script..., open the folder scripts\SceneForge (the installation summary shows its full path) and run the file SceneForge_odinstaluj_v...ms.
  2. Or: Scripting > New Script, paste the lines below and press Ctrl+E (Tools > Evaluate All):
(
  SF_odinst = getFiles ((getDir #userScripts) + "\\SceneForge\\SceneForge_odinstaluj_v*.ms")
  sort SF_odinst
  if SF_odinst.count > 0 then fileIn SF_odinst[SF_odinst.count]
  else messageBox "SceneForge is not installed."
)
  • It removes: the open panel (it first leaves isolation and the viewport filter mode and restores painted wireframe colours), the scene callbacks and the scene listener, the SceneForge columns in the native Scene Explorer, the loaded core, the files listed in SceneForge_installed.txt, the commands file, the startup menu script and the listener's own log file.
  • It keeps: your settings in plugcfg\SceneForge and any file in the plugin folder that SceneForge did not put there (the folder then stays). The final window lists what was removed, what was kept and where; delete the kept files by hand if you do not need them.
  • Data already saved inside your .max files stays in those files (see Privacy & footprint).
  • The menu entry disappears after you restart 3ds Max.

Right-click the column header and choose Which COLUMNS to show... (or the palette command Which columns to show...). Tick columns and move them with Up / Down. Defaults returns to the standard set.

The default set is Name, Class, Layer, State, Color, Material, Faces and Instances. Columns that read geometry (Faces, Verts, Mod., Size) are filled only for the rows you can see, in small steps, so a big scene stays responsive.

Sorting

Click a column header to sort, click again to reverse, a third time to go back to hierarchy order. Right-click the header for Sort by: name, class, layer, visibility, chronologically (creation order), face count, instance count, material, child count, depth in hierarchy, colour, hierarchy order. Which criteria to show... trims that menu; Reverse current order flips it.

Hierarchy

  • Click the triangle to expand or collapse a branch. Row menu Hierarchy: Collapse all, Expand all, Expand to level N, Collapse / Expand all lens headers. Collapsing works in hierarchy order only (no filter, no sorting, no lens).
  • Guide lines show who is whose child (Preferences, Hierarchy lines).
  • Show selected object (palette) expands the branches down to the selected object and scrolls to it.

Drag and drop

DragResult
Rows onto another rowLinks them as children of that object. Nothing moves in the viewport.
Rows onto an empty part of the listUnlinks them (they become scene roots).
Rows onto a layer in the layer listMoves them to that layer, in one undo step.
Rows onto a material header (by material lens)Assigns that material. Onto (no material) removes the material.
A material header onto a rowAssigns the material to that row, or to the whole selection if the row is selected.
Ctrl + dragSelects the rows you pass, with auto-scroll at the edges. Nothing moves.

If you link objects to a parent the filter hides, a bar says so and offers Show parent (clears the filter and scrolls to it) or Hide.

Renaming and double-click

  • F2 renames the current row in place. For many objects use Ctrl+F2 (see Batch rename).
  • Double-click a row: selects the object with its whole subtree (Preferences, Double-click). Double-click a camera: the active viewport looks through it.

Second view, pins, path bar, view tabs

  • Second view: show or hide adds a second list under the first one, with its own filter, lens and sorting. The selection is shared, because it belongs to the scene. Second view: copy settings from the top one starts it from the same point.
  • Pin (pin bar above the list) in the row menu keeps objects at hand above the list, whatever the filter. Click a pin to select it; right-click to unpin.
  • Path bar: show or hide: the ancestors of the current object as buttons; click one to select it.
  • View tabs: show or hide: your saved views as tabs above the list.

5. Selecting

  • A click on a row selects the object in the scene; Ctrl+click adds or removes; Shift+click selects a range. All of it is one undo step.
  • Ctrl+drag selects the rows you pass over.
  • A selection made in the viewport is highlighted in the list and the list scrolls to it (Preferences: Selection from the scene and scrolling).
  • Ctrl+A Select all in view selects what the list shows after the filter. Ctrl+D Clear selection clears the whole scene. Ctrl+I Invert selection works within the view.
  • Eye / snowflake in the State column: on a selected row it acts on every selected object; on an unselected row on that row only. One undo step.
  • Ctrl+Alt+S Show only selected: the list shows only what is selected and follows every change. Your filter text stays.
  • Alt+Left / Alt+Right Previous selection / Next selection: selection history like Back and Forward in a browser (up to 50 steps).
  • Row menu Select descendants, Select with descendants, Select similar to this object (same class, faces and size within 20%, same material; the query lands in the filter so you can edit it).
  • Select by size... (palette) asks for a condition such as >1000 and selects the result.
  • Copy names and Paste names from clipboard and select: names one per line (or separated by commas or semicolons) become a selection; missing names are listed in the status bar.

Named selection sets

  • Row menu Selection > Create set from selection..., Add to set, Remove from set (an emptied set is deleted).
  • The Set: list on the bottom bar selects the objects of a set. The number in brackets is the member count; an exclamation mark means part of the set points at objects that no longer exist.
  • Filter by set with set:Name. The panel warns once about a set without a name.

6. The filter and its language

The filter field accepts a plain piece of a name, and it also understands a small query language. The ? button shows the same cheat sheet inside the panel. While you type, the field suggests keys, and after the colon the values found in this scene.

Combining terms

- at the start of a termNOT-hidden:1
( a | b )OR (brackets can be nested)(type:Box | type:Sphere)

Names

Chips, history and switches

  • Category chips combine with OR (an object has one category), state chips with AND: Lights + Hidden = hidden lights. Category chips show how many objects of that kind the scene has. All / None / Invert work like Display in the Scene Explorer; x clears the chips and keeps the text. Hide the chip bar in Preferences or with Filter chips: show or hide.
  • hist. lists the last 20 queries the filter accepted; click one to use it again. The history is kept between sessions.
  • The filter box switches filtering off without deleting your query.
  • Filter delay (Preferences) sets how long the panel waits after the last key (250 ms by default).
  • A wrong query shows an error message, never a silent empty list. An unknown set name lists the existing sets.

8. Layers

The layer list

  • Shows every layer with its object count; the current layer is bold. Hide it with the Layer list box on the bottom bar or Layer list: show or hide.
  • Click a layer: puts layer:name into the filter. Double-click: makes it current.
  • Drag objects from the list onto a layer to move them. Drag a layer onto another layer to nest it; drop it on an empty part to move it back to the root. 3ds Max refuses loops (a parent under its own child).
  • Alt+click a layer: solo. Only that layer stays on; Alt+click again restores the previous layout. One undo step.

Layer menu (right-click a layer)

  • Hide layer / Show layer, Freeze layer / Unfreeze layer, Solo: only this layer (Alt+click) / End solo (restore layers).
  • Select the layer's objects (also those the filter hides), Set as current, Put into the filter as layer:.
  • New layer..., New layer UNDER ..., Layer color..., Rename layer....
  • Delete layer (3ds Max refuses a layer that holds objects) and Delete layer with sublayers... (asks what to do with the contents: move to layer 0, delete with the layers, or touch only empty layers; one undo step brings everything back).
  • Face budget for layer...: the layer list shows faces / budget and turns red above it. 0 removes it.

Layers from the row menu

Right-click objects, Layer: To the current layer, Choose layer... (a window with a name filter, quick with many layers), New layer from selection..., New empty layer..., Set the selection's layer as current, or pick a layer from the list.

Layer states Ctrl+Shift+L

Saves the visibility, freeze, lock and colour of all layers, and the current layer, under a name. Restore checked parts restores only what you tick; What changed? lists the differences layer by layer. The states are saved in the scene file. The same window also lists 3ds Max Scene States (Restore Scene State, Save Scene State (layers)...).

9. Groups, hierarchy and pivots

Groups

Row menu Group: Group... (asks for a name), Ungroup (one level), Explode (with nested), Open group, Close group, Detach from group. The palette also has Group selected and Ungroup. Filter with group:head, group:member or the by group lens.

Hierarchy

Unlink from parent makes the selected objects scene roots without moving them. Linking is done by dragging rows onto a row.

Pivot

Row menu Pivot (also in the palette as Pivot: ...). The objects do not move, only their pivot.

CommandPivot goes to
Center to objectThe centre of the bounding box (like Hierarchy > Pivot > Center to Object).
To bottom (on the floor)The middle of the lowest face of the bounding box in world space.
To topThe middle of the top of the bounding box.
To bounding-box cornerThe minimum corner; handy for tiling and arrays.
To world origin[0,0,0].
To parent's pivotThe parent's pivot position; objects without a parent are skipped and counted.
To common centre of selectionOne shared pivot: the centre of the whole selection.
Align to object / Align to worldRotates the pivot axes.
Copy orientation from first selectedThe pivot orientation of the first selected object, given to the others.
Reset pivot / Reset transform / Reset scaleThe 3ds Max reset commands.
Note. Changing pivot orientation on an object with non-uniform scale also moves and deforms it. 3ds Max does this without warning; SceneForge counts such objects and asks first. Run Reset scale before, if needed.

10. Isolation and viewport modes

CommandWhat it does
Isolate selected Ctrl+Alt+QHides everything except the selection and remembers the previous visibility of objects and layers. Press again to exit.
Isolate with descendantsThe same, with the whole subtrees of the selected objects.
Exit isolationRestores exactly what was visible before, including objects you had hidden by hand and layers that were off.
view: freeze the rest Ctrl+Alt+FFreezes everything the filter does not show. Those objects stay visible as a reference but cannot be clicked.
view: hide the restHides everything the filter does not show: isolation driven by the filter.
Release view Ctrl+Alt+FLeaves the viewport mode and restores the previous state.
X-ray the restSelected objects stay solid, everything else becomes See-Through. Click again to undo it on exactly those objects.
  • Isolation and the viewport filter modes are modes, not edits: Ctrl+Z does not leave them. Use the bar above the list or the same shortcut.
  • While the filter drives the viewport (hide the rest), isolation is not available; release the view first.

Viewport colouring

Viewport: color objects by layer / by class / by material / by face count (palette) replaces the wireframe colour of every object. By face count gives a green to red heat map of the scene's weight. This is a scene change: a bar above the list reminds you, and Restore wireframe colors (bar button or palette) brings back the originals in one undo step. If you save the file while painted, the painted colours are saved.

11. Command palette, Menu button and undo

Ctrl+P (while the panel has focus) opens the command palette: every panel command with a short description. Type a few letters in any order of words; letters need not be adjacent. While the field is empty or holds one or two letters, the commands you used last come first. A grey command shows why it is not available now.

The Menu button holds the same commands in groups: List and view, Viewport, Layers, Selection, Material, Objects, Reports and rules, Settings and tools, Configuration, Help and Other (for example the Pivot commands). Shortcuts are shown on the right.

The Help group has About SceneForge, Documentation, Report a bug..., Suggest a feature... and More plugins by the author, the same as the SceneForge menu.

Undo and redo

Every panel operation that changes the scene is one entry in the 3ds Max undo history. While the list has focus Ctrl+Z undoes and Ctrl+Y or Ctrl+Shift+Z redoes. In the filter field and the name editor Ctrl+Z undoes typing. Undo last operation and Redo undone operation are also in the palette.

If an undo block stays open (for example after an interrupted script), 3ds Max silently stops recording undo. The panel notices it and shows a yellow bar with Close block. The palette command is Close the stuck undo block. Use it only when no operation is running.

12. Scene reports

Reports button, Ctrl+Shift+R, or SceneForge > SceneForge - Scene reports. Nothing is computed when the window opens: each tab has its own button, so opening the window never stalls 3ds Max. Most tabs can select what they show and save it as CSV.

TabWhat it answers
Geometry duplicatesFind duplicates lists groups of objects with identical geometry. Check geometry compares vertex positions; Merge into instances turns a group into instances, Merge ALL does it for every group (groups whose geometry differs are skipped and named). Select group, CSV export.
Scene weightCompute scene weight: faces and objects per layer and per class; Select the chosen.
TexturesCheck textures: every bitmap file, its size on disk and whether it is missing. Relink missing... searches a folder (with subfolders) for files of the same name. Select objects using it.
NamingRules as name|regular expression, one per line. Check names, Select violators, Save rules, Preview and Fix names. Before fixing, the old names are written to a CSV file next to the scene.
Snapshot comparisonRemember baseline, later Compare: added, removed and changed objects. Show changed in the list puts is:changed into the filter.

13. Scene health (Scene Doctor)

The Health button (also Scene health in the palette and the row menu) scans the whole scene for things that raise no error but spoil the work. Findings are listed with counts, most serious first; zero findings stay on the list in grey, so checked and clean is visible.

  • Show these objects (or double-click a finding) selects them and puts is:selected into the filter.
  • Fix repairs a finding when the fix is unambiguous. A Scene Doctor confirmation says how many objects it touches. One undo step reverts it.
  • Recompute rebuilds the snapshot and checks again.

14. Scene rules

Scene rules... (palette, side bar) stores rules made of a filter query and an action. A rule works on the whole scene, also on objects the list does not show.

  • Fields: Name, Query (filter language), Action, Argument (the layer name for Move to layer).
  • Actions: Hide, Show, Freeze, Unfreeze, Select in scene, Display as box: on / off, See-Through: on / off, Disable rendering, Enable rendering, Move to layer (argument).
  • Test counts matching objects and changes nothing. Run runs one rule; Run all runs them top to bottom after showing the counts. Each run is one undo step.
  • Automatic rules (Preferences, off by default): after opening a file and after an import the panel waits 1.5 s and runs all rules (after an import only on the new objects).

15. Batch rename and name by template

Batch rename Ctrl+F2

Works on the selected objects. The steps always run in this order: base name, trim, find and replace, letter case, number, prefix and suffix.

  • Base name (empty keeps the names), Prefix, Suffix, Trim characters from the front / from the end.
  • Find / Replace with, with regular expression (groups $1, $2 work) and case sensitive.
  • Letter case: no change, UPPERCASE, lowercase, Each Word Capitalized.
  • Numbering: start, step, digits. The order is the row order in the list, so sort the list first.
  • The preview shows now and after change, counts repeated names and skips rows that would get an empty name. Rename applies it to all selected objects in one undo step and saves the old names to a CSV file next to the scene.

Name by template

Row menu Name by template...: a template with tokens {name}, {class}, {layer}, {mat} and a counter {##} (as many digits as hashes), for example {layer}_{class}_{##}. Preview, then Rename, one undo step.

16. Object properties, materials, cameras and lights

Object properties Alt+Enter

The General properties of 3ds Max for many objects at once: Hidden, Frozen, See-Through, As box, Backface cull, All edges, Vertex ticks, Trajectory, Ignore in Zoom Extents, Frozen in material color, vertex colour display, Renderable and more. A field whose value differs between objects shows a mixed state and is not written until you change it.

Display and rendering (row menu)

  • Hide, Show, Freeze, Unfreeze, Renderable: on / off.
  • Display: As box, See-through, Backface cull, All edges, Vertex ticks, Trajectory, Frozen in color (on / off).
  • Inherit from layer: display, motion blur and colour, each take from layer or set on the object. An object that takes a property from its layer ignores its own setting.
  • Object color..., Zoom in viewport.

Materials

  • Row menu Material: Open material in editor (Slate or classic, whichever mode is on), Put material into the active slot of the classic editor, Assign material from slot (the 24 classic slots), Assign material from Slate editor, Copy material from the first selected to the rest (the same material, not a copy), Replace this material in the whole scene with..., Remove material, Show objects with this material (filter).
  • Under the by material lens, drag rows onto a material header to assign it.

Instances

Row menu Instances: Select all instances of this object, Select instances TOGETHER with references, Show only instances (filter), Count instances in the scene.

Cameras and lights

  • Create camera from view (palette): a camera that matches the active perspective view, in the class of the current renderer (V-Ray Physical Camera, Corona Camera, FStorm Camera, or a Physical Camera for Arnold and the others). The viewport switches to it. One undo step.
  • Look through this camera (or double-click a camera row).
  • Turn lights on / Turn lights off for the selected lights, one undo step.
  • Render selected cameras in sequence... (EXPERIMENTAL, enable in Preferences, Render queue): each selected camera is rendered with the current renderer to folder\camera_name.png. 3ds Max is blocked until the queue ends. Save the scene first.

Tags and notes

Row menu Tags... (labels separated by commas) and Note.... They are stored as user properties sf_tag and sf_note (visible in Object Properties > User Defined) and saved with the .max file. Columns Tags and Note, filter tag: and note:. Empty text removes them.

Containers

Containers in the scene... lists containers with their state and source file. The row menu Container has Open, Close, Load contents, Unload contents, Reload, Update from source file, Make unique and Merge source into scene. Commands that need a source file refuse (and say why) when the container has never been saved.

Columns in the native Scene Explorer

Max explorer with SceneForge columns opens a 3ds Max Scene Explorer with extra columns (instances, children, depth, subtree size and a short note). Add SceneForge columns to your own explorer appends them to the explorer you use; Remove SceneForge columns from explorers takes them off.

Delete

Row menu Delete deletes the selected objects in one undo step and asks first when there are many.

17. Macros, states, views and configuration

Macros

  • Macro: start recording, then work: filters, palette, Menu and shortcut commands and row menu actions are noted. Macro: stop and save... asks for a name.
  • Each macro becomes a palette command Macro: name, so it can also get its own shortcut.
  • Macros: list, run, delete... shows the steps, runs or deletes macros (stored in makra.json).

Object visibility states

Object visibility states...: named snapshots of which objects are hidden and frozen. Save current state..., Restore (exactly that layout, one undo step), Delete state. Saved in the scene file.

Saved views

  • A view remembers filter, sorting, lens, column widths and the panel split. It does not remember the selection.
  • Views button or Save current view...; the first nine load with Ctrl+1 to Ctrl+9. Manage views... renames, reorders, overwrites and deletes them.
  • Views are stored in the plugin settings, not in the scene file.

Configuration

  • Configuration: remember panel state on/off: filter, sorting, lens, column widths, split and the second view are saved by themselves and come back when the panel opens. On by default.
  • Configuration: save to file... / load from file...: preferences, layout and views in one JSON file, to keep several set-ups or move them to another computer.
  • Configuration: save current as default / load default.
  • Panel settings in the scene file: save now writes filter, lens, columns, pins and budgets into the scene (see Privacy & footprint).

The Performance button sits under the status line. Next to it, Geometry: tells you the state of the automatic face and vertex counting (for example not checked, pending, automatic counting paused).

Menu itemWhat it does
Light modeA switch. Pauses the automatic geometry counting: the Faces, Verts, Size and Mod. columns, the layer face budgets and the footer counters. Use it on very heavy scenes. The setting is remembered.
Recalculate selected geometryCounts faces for the selected objects now, on demand.

22. Reporting bugs

Thank you for testing. Every report is read.

How to report

  • In 3ds Max choose SceneForge > Report a bug... (also in the panel: Menu > Help, or the palette).
  • It copies your set-up details to the clipboard and asks: Yes opens the GitHub bug form, No opens your e-mail program. Nothing is sent automatically.
  • Describe what you did, what you expected and what happened instead. Then paste the details (Ctrl+V). A screenshot helps a lot.
  • GitHub: github.com/Forge-Plugins/SceneForge/issues   E-mail: forgeplugins@gmail.com
  • Ideas: SceneForge > Suggest a feature..., the same two ways.
Check before you post publicly. The copied details contain the SceneForge and 3ds Max versions, the 3ds Max language, the Windows version, the install folder (it includes your Windows user name), the number of objects in the scene and the last lines of the panel log, which can contain file paths and object names. Read the text before you paste it on GitHub. For client scenes, send the report by e-mail instead.

What helps

  • The steps to repeat the problem, and how often it happens.
  • Roughly how many objects and layers the scene has, and which renderer is active.
  • For a freeze or a slow operation: switch on Performance > Record callback diagnostics, repeat the problem, switch it off, then send the panel log dziennik_panelu.txt from plugcfg\SceneForge.
  • Any message from the MAXScript Listener (F11).

23. Privacy & footprint

Network

SceneForge works offline. It does not connect to the internet, sends no data and has no telemetry. A browser or e-mail program opens only when you choose Report a bug..., Suggest a feature... or More plugins by the author.

What can end up in your .max files

WhatWhenHow to avoid or remove it
Panel settings: filter, lens, visible columns, pins, face budgets (in the scene root's appData)Every time you save, while Scene file is on (default). Also with Panel settings in the scene file: save now.Preferences > Scene file off.
Object visibility statesOnly when you save one.Delete the state in its window.
Layer statesOnly when you save one.Delete the state in its window.
A marker that automatic rules already ran on this fileOnly with Automatic rules on.Keep Automatic rules off (default).
Tags and notes: user properties sf_tag, sf_noteOnly when you set them.Set empty text, or edit Object Properties > User Defined.
Painted wireframe coloursOnly after Viewport colouring, until you restore them.Restore wireframe colors before saving.
Material SceneForge_DefaultOnly when you use the Health fix for missing materials.Delete or replace it like any material.

Everything else the panel does (isolation, viewport filter modes, X-ray, lenses, filters) lives only in memory and is not written to the file. Normal scene edits you make through the panel (renames, layers, hiding, materials ...) are of course saved like any other edit.

Files on your disk

  • Plugin files in scripts\SceneForge, usermacros and scripts\startup (see Where the files go).
  • Settings, macros, views, rules and the panel log in plugcfg\SceneForge. The log is capped at 1 MB; the previous part is kept once.
  • scripts\SceneForge_events_log.txt: written by the scene listener only if something goes wrong.
  • CSV files you save, the old-names CSV next to the scene after renames, exported layers, rendered images and scene cards, only where you choose (or next to the scene).

24. Known limitations in this beta

  • 3ds Max 2027 only. This package does not install in other versions.
  • Very large scenes (around 50 000 objects): selecting or deselecting everything can take a moment, because 3ds Max redraws the viewport.
  • Undo and redo after deleting very many objects can take a long time. This is how 3ds Max itself handles that undo step.
  • Merge file with name check cannot be undone with Ctrl+Z (3ds Max records no history for a merge). The merged objects stay selected, so you can delete them.
  • Isolation and the viewport filter modes are modes, not undo steps.
  • Panel shortcuts, including Ctrl+P, work only while the panel has focus.
  • Features marked EXPERIMENTAL (footer counters, render queue, Expert mode) are not fully tested.
  • The filter does not yet support is:zeroscale, is:nonuniform, is:faraway or has: keys.
  • The user interface is in English only.
